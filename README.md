# YaDisk Downloader

Бесплатная программа для Windows, которая скачивает файлы с Яндекс Диска через браузерную версию сайта. Поддерживает личный Диск и публичные ссылки, сохраняет папки и продолжает очередь после остановки. REST API Яндекс Диска не используется.

## Скачать программу

Откройте **[Releases](https://github.com/zd333753-pixel/yadisk-downloader/releases/latest)** и скачайте `YaDiskDownloader-Windows.zip`. Распакуйте архив в отдельную папку и запустите `YaDiskDownloader.exe`. Python устанавливать не нужно. Нужен установленный Google Chrome; программа использует собственный профиль, обычные окна Chrome остаются свободны.

Для Windows 10/11 x64. Сборка не имеет цифровой подписи.

## Возможности

- Публичные ссылки на файлы, папки и фотоальбомы: `disk.yandex.ru/d/…`, `/i/…`, `disk.360.yandex.ru`, `yadi.sk`.
- Скачивание с личного Диска после самостоятельного входа в браузере программы.
- Выбор **1, 5, 10 или 50** загрузок в группе.
- Вложенные папки, подпапка с названием источника и защита от перезаписи существующих файлов.
- Пауза, журнал ошибок, ограниченные повторные попытки и **«Скачать / продолжить»**.
- Проверка имени и размера скачанного файла, свободного места и уже готовых файлов.

## Как пользоваться

1. Выберите **«Публичная ссылка»** и вставьте ссылку. Для своего Диска выберите **«Мой Яндекс Диск»**, нажмите **«Открыть браузер / вход»**, самостоятельно войдите и откройте нужную папку. Нажмите **«Готово»** в программе. Пустой путь означает весь личный Диск.
2. Выберите папку для сохранения. Для разных источников используйте отдельные папки.
3. При необходимости включите **«Создать подпапку с названием файла/папки»**. Для одиночного файла используется имя без расширения.
4. Выберите число файлов в поле **«Одновременно»** и нажмите **«Скачать / продолжить»**. Сканирование выполняется автоматически; ZIP всей папки не создаётся.

Настройки личного Диска и публичной ссылки запоминаются отдельно. В **«Настройках»** находятся фоновый режим, временная папка, пропуск ошибок и применение ответа к следующим ошибкам. Пароль в программу вводить не нужно.

Кнопки **Ⅱ**, **×** и **F8** запрашивают остановку. Уже начатая группа завершается и сохраняется; файлы и очередь не удаляются. Процент в карточке показывает долю готовых файлов всей очереди. Количество реально передаваемых файлов и скорость зависят от Chrome и сервера Яндекса.

## Ошибки и докачивание

Ошибки записываются в `Не скачано.csv` внутри фактической папки копии. Нажмите **«Список ошибок»**, чтобы открыть журнал. Если автопропуск выключен, программа предлагает повторить, пропустить или остановить; повтор ограничен тремя попытками за проход.

Для докачивания выберите тот же источник, папку и состояние галочки подпапки, затем нажмите **«Скачать / продолжить»**. Готовые файлы проверяются и пропускаются, ошибочные повторяются. Не удаляйте `.yd-browser-progress.sqlite3`: это база очереди. CSV служит журналом, его редактирование не меняет очередь. Незавершённый файл скачивается заново; побайтового продолжения нет.

Временная папка и папка копии должны вмещать начатую группу и резерв 512 МБ. На разных дисках перенос временно требует две копии. Существующие файлы не перезаписываются — добавляется «копия N».

## Приватность

Профиль браузера хранится локально в `%LOCALAPPDATA%\YandexDiskCopier\BrowserProfile`. Cookies обычного Chrome не копируются. Настройки, личные ссылки, журналы, браузерный профиль, база очереди и скачанные файлы не входят в репозиторий или архив программы. Приложение не отправляет телеметрию разработчику; браузер обращается к сайту Яндекса при работе.

Для исправления ошибки Chromium перед запуском собственного профиля создаётся резервная копия `History`, затем очищаются только три таблицы истории загрузок. Посещения и cookies сохраняются. История обычного Chrome не изменяется.

При проверке, запросе пароля или CAPTCHA снимите галочку фонового режима и выполните необходимые действия самостоятельно. Запрет скачивания владельцем и ограничения сервера не обходятся. [Правила публичного скачивания Яндекса](https://yandex.ru/support/yandex-360/customers/disk/web/ru/share/sharing-to-me.html).

## Из исходников

Нужны Windows x64, Python 3.12 и Google Chrome.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe downloader.py
```

Сборка единого EXE:

```powershell
.\build.ps1
```

Файл появится в `dist\YaDiskDownloader.exe`. Если политика PowerShell не позволяет запускать скрипт, выполните команды сборки вручную:

```powershell
.\.venv\Scripts\python.exe build_icon.py
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --onefile --windowed --name YaDiskDownloader --collect-all playwright --icon app.ico --add-data "app.ico;." downloader.py
```

Тесты используют временные каталоги, локальный HTTP-сервер и перехваченные страницы; доступ к личному Диску не нужен:

```powershell
.\.venv\Scripts\python.exe -m unittest test_downloader test_background_browser test_parallel_public
```

Проверяются группы 5/10/50, реальные пять перекрывающихся браузерных загрузок, пауза, ошибки, докачивание, вложенные папки, публичные файлы и сохранение профиля. Интерфейс сайта может меняться, поэтому при сбое проверьте журнал и видимый браузер. Не переводите компьютер в сон во время загрузки.
